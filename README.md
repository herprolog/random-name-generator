名前ジェネレーター

用途や雰囲気に合わせて、日本語の名前をランダムに生成できるWebツールです。

主な機能

- 名前の雰囲気を選択
  - 現代風
  - 古風
  - 中性的
  - ファンタジー風
- 生成人数の指定
  - 1人・5人・10人
- 重複を避けた名前の生成
- 個別の名前をコピー
- 生成結果をまとめてコピー
- CSV形式で保存

特徴

- HTML・CSS・JavaScriptのみで動作
- サーバー不要
- インターネット接続不要で利用可能
- スマートフォン・パソコンに対応
- 無料で利用可能

使い方

1. 名前の雰囲気を選択します。
2. 生成する人数を選択します。
3. 「名前を生成」ボタンを押します。
4. 表示された名前をコピー、またはCSV形式で保存します。

使用技術

- HTML
- CSS
- JavaScript
